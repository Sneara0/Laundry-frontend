# PRESSIO - Color Codes

## Brand Colors (CSS Variables in globals.css)

| Variable | Hex Code | Usage |
|----------|----------|-------|
| `--brand-primary` | `#375a79` | Main brand color - navbar, hero bg, dropdowns, logo text, borders |
| `--brand-primary-dark` | `#2d4a63` | Darker shade - gradient endpoint |
| `--brand-accent` | `#a8d14a` | Accent green - hero heading, CTA button |
| `--brand-hover` | `#2ea2cc` | Hover color - navbar border on hover |

## Shadow Colors

| Variable | Value | Usage |
|----------|-------|-------|
| `--brand-pink-shadow` | `rgba(219,112,147,0.12)` | Navbar shadow when scrolled |
| `--brand-pink-shadow-light` | `rgba(219,112,147,0.08)` | Navbar shadow default |

## Scrollbar Colors

| Variable | Value | Usage |
|----------|-------|-------|
| `--brand-scrollbar` | `#375a7940` | Mobile menu scrollbar thumb (25% opacity) |
| `--brand-scrollbar-hover` | `#375a7980` | Scrollbar thumb hover (50% opacity) |

## Font

- **Primary Font:** Montserrat (300-900 weights)
- **CSS Variable:** `--font-montserrat`
